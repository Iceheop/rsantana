# Portafolio personal

Sitio de portafolio en Astro con estructura orientada a escalabilidad por modulos.

## Scripts

- `npm run dev`: servidor local.
- `npm run typecheck`: validacion de tipos y colecciones de contenido.
- `npm run build`: compilacion para produccion.
- `npm run ci`: chequeo completo (`typecheck + build`).
